# 🎴 Flashcard React Application

A modern, interactive, and responsive Flashcard web application built with **React**, **TypeScript**, and **Tailwind CSS**. Designed to help developers learn and test their knowledge on JavaScript & React concepts efficiently.

---

## 🚀 Features

* **Interactive Cards**: Smooth toggle mechanism to switch between questions and answers.
* **Progress Tracking**: Real-time progress bar reflecting the current card position out of the total stack.
* **Responsive & Dynamic UI**: Fully custom-styled components built with Tailwind CSS, supporting clean micro-interactions.
* **Type Safety**: Built with TypeScript for reliable type checking and predictable component state.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React.js (Hooks & Functional Components)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Build Tool:** Vite / Create React App

## ⚙️ Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/flashcard-app.git

```


2. **Navigate to the project directory:**
```bash
cd flashcard-app

```


3. **Install dependencies:**
```bash
npm install

```


4. **Start the development server:**
```bash
npm run dev

```
